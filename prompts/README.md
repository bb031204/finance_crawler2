# Qwen 提示词

本目录文件是实际发送给本机Qwen的提示词，程序启动时加载。Markdown用于分清任务与规则；模型仍只输出规定JSON，不输出Markdown、长推理或额外分析字段。修改后在下一次启动生效。

| 文件 | 职责 |
| --- | --- |
| plan.md | 普通检索规划 |
| coverage.md | 按行业/市场分组规划 |
| coverage_repair.md | 只修复缺失或不合格查询组 |
| screen.md | 宽进严出地筛选候选 |
| date.md | 核验原始发布日期 |
| read.md | 先取舍，再提炼主体、变化与对象 |
| merge.md | 去重并合并同篇信息 |
| compact.md | 合并输入超限时整理中间笔记 |
| industry.md | 提炼文件名使用的主要产业 |

## 选取目标

这些市场文本后续将输入语言编码器，再与股票时序网络融合，辅助下一交易日收益率预测。Qwen负责已发表事实与有归属观点的筛选和概括，不自行预测股价、收益率或涨跌方向，也不以事后收益筛选样本。

保留公司经营/财报、资金交易、股东行为、供需价格、风险、宏观政策，以及有依据和归属的分析。无证券代码的公司、行业或宏观信息仍可用；代码和交易所不得按常识补猜。

## 主要内容的取舍与长度

- 先判断哪些是实质市场信息，哪些只是模板句，再写一段“主体→动作/变化→对象或业务”，补关键期间、数字单位、比较基准、原因条件与观点归属。
- 通常中文200至350字、英文120至190词；短讯更短。关键事实较多可适度超出，不硬截原文或摘要，不为满足字数填充背景。
- 删营销、导航、评论、重复背景、例行一致通过票数、委员会传递与签署套话；保留实质分红/融资/人事决定、合同和批准条件。原文自夸也不能直接当事实复述。
- 只发布财报的封面而无实际业绩或实质事项、纯程序性通知可判断useful=false，不为增加文件数存成空泛文章。

程序有轻量兜底：明显超长、空泛评价等沿用既有最多一次模型修正；对整句完全匹配已确认程序模板的文本，保守清理并记内部审计标签。混合事实句、存在反对票的争议决议和实际金融合同不靠这套模板删除。正常输出不增加额外的“先判断”模型调用。

正式JSON仍为十字段，输出清理标签只进内部审计。历史JSON本次不批量改写；新生成或按现有入口重新提炼的记录使用新规则。发布日期及实际feature_available_at仍分开保存。

## 验证快照

340项离线回归检查通过。已有真实英文原文样本的主要内容由1345字符缩至978字符（约减少27.3%），关键业绩数字及比较期间保留。合成中文样本保留营收、利润、原文代码、分红与批准条件，清理票数/签署/送审；这些合成记录只在隔离验证目录，不能作真实公告使用。无代码宏观及有归属观点仍入选，程序性通知和纯披露封面被排除。

验证见logs/market_prompts_validation.json与logs/market_prompts_full_tests.txt。初轮也发现并记录了复制营销句和日期引用失败，没有据此降低事实或日期校验。最终轮重用同一模型的已验证响应缓存，并重新经过当前清理/校验，未重复消费模型调用。各轮本地推理合计32次，真实搜索0、下载0、正式数据写入0；不代表全量事实准确率或固定提速比例。

当前长文样本仍只需一个阅读分片；提示词估算由607增至768 token，未增加一轮固定分析或全面提高上下文/输出预算。历史发现的稳定配置标识保持不变，不重放已提交搜索。旧进程不中断，验证完成后恢复原有“自然结束后再按config运行一次”的等待安排。
